# 图形化编程原型

## 主页与作品

- 访问 `/` 打开主页，`/#editor` 可直接打开编辑器。
- 主页参考本地 EST STUDIO 的侧边导航和最近文件布局，提供我的作品、积木示例及新建作品。
- 每个作品独立保存在当前浏览器，支持打开、重命名、复制和删除；返回主页时保存当前作品。
- 编辑器的保存和读取针对当前作品；旧版 `visualProgramV2` / `visualProgramV1` 存档首次迁移为“原有作品”，不删除旧存档。
- 示例会创建独立作品，不代表已接入或执行真实硬件。
- `home.js` / `home.css` 负责主页；`block-layout.js` / `blocks.css` 负责横向积木几何和样式。
- 主页导航图片沿用本地 EST STUDIO 主页的 `home-icon-file.png` 和 `home-icon-build.png`；作品缩略图由实际积木数据生成。
- 浏览器回归脚本：`tests/home.spec.cjs`、`tests/blocks.spec.cjs`。需要可解析的 Playwright 包及本机 Edge，服务地址为 `http://127.0.0.1:4173/`。

这是一个面向手机横屏使用的图形化编程 Web App 原型。产品方向参考 WeDo/Scratch 这类拖拽式编程体验：用户可以从底部素材区选择卡片，拖放到上方工作区，组成一串可编辑的程序卡片。

## 蓝牙连接

- 编程页顶部的“蓝牙”按钮进入 `/#bluetooth`，返回编程不会清空程序。
- 搜索使用浏览器原生设备选择器，选择后建立 BLE GATT 连接，支持断开、重连和断连状态提示。
- 需要支持 Web Bluetooth 的浏览器，以及 HTTPS 或本机 localhost / 127.0.0.1。手机通过局域网 HTTP 地址访问不能使用网页蓝牙。
- 按 Spark_AI 名称搜索并发现 FFF0/FFF1 服务，订阅通知后进入就绪状态。
- 黄色按钮编译当前程序并分块上传运行；灰色按钮发送 B9 停止，不支持从暂停位置恢复。
- 全部22种现有积木已接入本机 Pika 编译，包括持续运动、独立功率、组合电机（左E右F）、条件等待、音符拍数和点阵。持续运动需用对应停止块结束，非法参数仍整单阻止发送。
- 电脑发送需另运行 `node compiler-server.cjs`；手机编译尚未支持。
- 通讯格式、编译器配置、ACK兼容风险和测试边界见 [COMMUNICATION.md](COMMUNICATION.md)。
- `tests/bluetooth.spec.cjs` 使用模拟蓝牙接口验证状态、错误及页面切换；不代表已通过真实硬件测试。

## 当前定位

- 使用场景：手机或平板横屏使用
- 交互方式：从素材区拖拽卡片到工作区
- 程序结构：从“开始”卡片出发，按从左到右的顺序组织
- 当前重点：先打磨图形化编辑器的工作区交互，后续再接入 Python 生成和机器人通信

## 当前功能

- 横屏主界面：上方程序区，下方卡片库
- 五个素材选项卡：选项卡A、选项卡B、选项卡C、选项卡D、暂存
- 卡片操作：拖入、排序、删除、同时抓取移动与组合暂存
- 组合暂存：将抓手选中的多张卡片停留在素材区 1 秒后暂存，之后可整组拖回程序区
- 快捷抓取：在程序区空白处静止按住 0.5 秒可启动合并抓手；暂存区底部空白带可左右浏览
- 画布浏览：程序区隐藏横纵滚动条，可拖动空白区域自由挪动画布
- 控制结构：循环卡片，支持循环嵌套显示
- 参数卡片：等待、超声波传感器、5x5 点阵屏
- 程序操作：撤销、前进、保存、读取、清空
- 本地保存：使用浏览器 localStorage 保存当前程序

## 本地预览

进入项目目录后启动一个静态服务：

```bash
python -m http.server 4173 --bind 0.0.0.0
```

电脑浏览：

```text
http://127.0.0.1:4173/
```

手机浏览：

```text
http://电脑局域网IP:4173/
```

手机需要和电脑在同一个网络下，并横屏使用。

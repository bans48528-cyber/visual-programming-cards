# 图形化编程原型

这是一个面向手机横屏使用的图形化编程 Web App 原型。产品方向参考 WeDo/Scratch 这类拖拽式编程体验，但第一版刻意保持简单：孩子可以从底部卡片库选择卡片，放到上方程序区，并按顺序运行。

## 当前定位

- 使用场景：手机或平板横屏使用
- 交互方式：点击添加卡片，或拖拽卡片到程序区
- 程序结构：从“开始”卡片出发，按从左到右的顺序执行
- 运行反馈：运行时高亮当前卡片，可展开运行预览面板查看小车动作

## 第一版功能

- 横屏主界面：上方程序区，下方卡片库
- 四个卡片分类：选项卡A、选项卡B、选项卡C、选项卡D
- 卡片操作：添加、拖拽排序、删除
- 程序操作：运行、保存、读取、清空
- 运行预览：默认隐藏，通过“预览”按钮展开
- 本地保存：使用浏览器 localStorage 保存当前程序

## 本地预览

进入项目目录后启动一个静态服务：

```bash
python -m http.server 4173 --bind 0.0.0.0
```

电脑浏览：

```text
http://127.0.0.1:4173/
```

手机浏览：

```text
http://电脑局域网IP:4173/
```

手机需要和电脑在同一个网络下，并横屏使用。

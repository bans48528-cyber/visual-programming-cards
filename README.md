# 小白编程 Android 1.2.3

当前分支：xiaobai/remote-blocks。基于 ddb4db7 开发。

- 支持小白积木、作品保存与手动遥控。手机负责程序顺序、循环和等待时间；设备按 C2 指令执行电机、红外、显示和语音动作。
- 手动遥控仍使用 C1：Y/A 控制左电机正/反，X/B 控制右电机正/反，L 加速、R 减速。
- 编程界面进入编程模式并保持心跳；遥控界面进入遥控模式。定时动作与条件等待按序号等待 DONE。程序停止发送 STOP_PROGRAM。
- Android 原生允许校验通过的 C1/C2 定长帧，优先写 FFF2，订阅 FFF1，必要时退回 FFF1 写入。
- 蓝牙自动连接默认设备；首次使用选择信号最强的兼容设备。支持设备本地改名，默认设备和名称会保留。
- APK：artifacts/xiaobai-1.2.3-debug.apk，包名 com.xiaobai.remote，可与原软件并存。
- 构建：powershell -ExecutionPolicy Bypass -File scripts/android.ps1。无需 Pika 编译器。
- 测试：npm test。安装及验证范围见 [小白安装说明](docs/XIAOBAI_APP.md)。

以下保留原 Spark 项目的历史说明，其中编译、上传、传感器和点阵能力不适用于小白版。

# 图形化编程原型

## Android 界面预览版

已新增复用现有编辑器的 Capacitor Android 工程。测试 APK 位于 `artifacts/card-programming-0.1.0-debug.apk`，支持离线编程、设备内保存、手机蓝牙页面及本机编译发送。原生编译已通过 29 组各两次与桌面字节码的完整对照。已实现原生 BLE 扫描、连接与 D0 状态读取；权限与扫描通过手机测试，一加 7 Pro 与 Spark_AI 已通过连接、状态读取及 287 字节程序发送，等待程序运行与软件暂停已通过主机状态上报验证，外设动作待验收。安装、构建与验证范围见 [ANDROID.md](ANDROID.md)。

Node.js 22+ 环境下运行 `npm ci`、`npm run android:build`；当前 Windows 电脑也可运行 `powershell -ExecutionPolicy Bypass -File scripts/android.ps1`。

## 主页与作品

- 访问 `/` 打开主页，`/#editor` 可直接打开编辑器。
- 主页参考本地 EST STUDIO 的侧边导航和最近文件布局，提供我的作品、积木示例及新建作品。
- 顶部参考本机 EST Studio 2.8.38 的引导卡：两行标题、大图标新建/返回编辑入口、积木与机器人演示动画。演示直接复用编辑器的真实积木组件与横向布局（开始、电机正转、笑脸点阵），不连接或驱动硬件；支持减少动态效果，手机横屏使用紧凑布局。最近作品保持每行 4 个（窄屏竖排自适应）。
- 每个作品独立保存在当前浏览器，支持打开、重命名、复制和删除；返回主页时保存当前作品。
- 编辑器的保存和读取针对当前作品；旧版 `visualProgramV2` / `visualProgramV1` 存档首次迁移为“原有作品”，不删除旧存档。
- 示例会创建独立作品，不代表已接入或执行真实硬件。
- `home.js` / `home.css` 负责主页；`block-layout.js` / `blocks.css` 负责横向积木几何和样式。
- 主页导航图片沿用本地 EST STUDIO 主页的 `home-icon-file.png` 和 `home-icon-build.png`；作品缩略图由实际积木数据生成。
- 浏览器回归脚本：`tests/home.spec.cjs`、`tests/blocks.spec.cjs`。需要可解析的 Playwright 包及本机 Edge，服务地址为 `http://127.0.0.1:4173/`。
- 数值参数点击数值后使用内置小键盘，不弹系统键盘；支持小数、删除、清空、取消和确定，保留加减按钮。确定才保存，取消保留原值。网页与 Android 共用，回归测试为 `npm run test:keypad`。

这是一个面向手机横屏使用的图形化编程 Web App 原型。产品方向参考 WeDo/Scratch 这类拖拽式编程体验：用户可以从底部素材区选择卡片，拖放到上方工作区，组成一串可编辑的程序卡片。

## 蓝牙连接

- 编程页顶部的“蓝牙”按钮进入 `/#bluetooth`，返回编程不会清空程序。
- 搜索使用浏览器原生设备选择器，选择后建立 BLE GATT 连接，支持断开、重连和断连状态提示。
- 需要支持 Web Bluetooth 的浏览器，以及 HTTPS 或本机 localhost / 127.0.0.1。手机通过局域网 HTTP 地址访问不能使用网页蓝牙。
- 按 Spark_AI 名称搜索并发现 FFF0/FFF1 服务，订阅通知后进入就绪状态。
- 电脑版黄色按钮编译当前程序并分块上传运行；灰色按钮使用 B9 模拟硬件按键，其含义不是幂等急停，详见通信文档。安卓黄色按钮本机编译并发送到 0 号槽位，并请求运行；灰色按钮按网页版逻辑请求暂停，详见 [发送说明](docs/ANDROID_UPLOAD.md)。
- 全部23种现有积木已接入本机 Pika 编译，包括持续运动、独立功率、组合电机（左E右F）、条件等待、音符拍数和点阵。持续运动需用对应停止块结束，非法参数仍整单阻止发送。
- 电脑发送需另运行 `node compiler-server.cjs`；手机使用 APK 内的自定义编译库，无需电脑编译服务。
- 通讯格式、编译器配置、ACK兼容风险和测试边界见 [COMMUNICATION.md](COMMUNICATION.md)。
- `tests/bluetooth.spec.cjs` 使用模拟蓝牙接口验证状态、错误及页面切换；不代表已通过真实硬件测试。

## 当前定位

- 使用场景：手机或平板横屏使用
- 交互方式：从素材区拖拽卡片到工作区
- 程序结构：从“开始”卡片出发，按从左到右的顺序组织
- 当前重点：先打磨图形化编辑器的工作区交互，后续再接入 Python 生成和机器人通信

## 当前功能

- 横屏主界面：上方程序区，下方卡片库
- 五个素材选项卡：选项卡A、选项卡B、选项卡C、选项卡D、暂存
- 卡片操作：拖入、排序、删除、同时抓取移动与组合暂存
- 组合暂存：将抓手选中的多张卡片停留在素材区 1 秒后暂存，之后可整组拖回程序区
- 快捷抓取：在程序区空白处静止按住 0.5 秒可启动合并抓手；暂存区底部空白带可左右浏览
- 画布浏览：程序区隐藏横纵滚动条，可拖动空白区域自由挪动画布
- 控制结构：循环卡片，支持循环嵌套显示
- 参数卡片：等待、超声波传感器、5x5 点阵屏
- 程序操作：撤销、前进、保存、读取、清空
- 本地保存：使用浏览器 localStorage 保存当前程序

## 本地预览

进入项目目录后启动一个静态服务：

```bash
python -m http.server 4173 --bind 0.0.0.0
```

电脑浏览：

```text
http://127.0.0.1:4173/
```

手机浏览：

```text
http://电脑局域网IP:4173/
```

手机需要和电脑在同一个网络下，并横屏使用。

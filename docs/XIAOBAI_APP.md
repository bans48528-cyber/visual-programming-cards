# 小白编程 1.2.3 测试版

安装包：`artifacts/xiaobai-1.2.3-debug.apk`。Android 7.0 及以上；包名 `com.xiaobai.remote`。这是调试签名的测试包，可与原“卡片编程”分开安装。

## 使用

1. 打开小白电源。手机与实体遥控器同一时间只能有一个连接设备。
2. 打开编程或遥控界面时，APP 自动连接默认设备；首次使用扫描 3 秒，连接信号最强的兼容设备。默认设备 10 秒内找不到时提示重试或手动选择。
3. 编程界面会发送 `ENTER_PROGRAM` 并保持心跳。遥控界面会发送 `ENTER_REMOTE`，方向键或电机键按住时每 40 毫秒重发 C1，松手发全零帧。
4. 放入积木后点“运行”。手机执行顺序、循环和等待时间；设备执行 C2 动作。定时电机、等待红外和等待词条须收到对应 `DONE` 才继续。红外等待固定使用中间通道。
5. 点“停止”会发送 `STOP_PROGRAM`，由设备取消等待并刹停电机。实体按键退出编程模式、断连或切后台时，手机取消当前程序；重连后不会自动恢复。

持续运动、功率和停止积木仍按用户排列的顺序发送。相邻指令的 BLE 传输会耗费实际时间；需要确定运行时间时请使用等待或定时积木。

遥控键位：Y 左正、A 左反、X 右正、B 右反，L 加速、R 减速。积木中的电机端口显示为 L/R。

## BLE 接入

订阅 FFF1 通知，优先写 FFF2；状态查询无回报且设备支持时，尝试 FFF1 写入。C1/C2 均为 17 字节定长帧，相邻发送起点间隔至少 30 毫秒，不在上一帧写入完成后再额外等待 30 毫秒。编程心跳间隔 400 毫秒，设备事件与 `DONE` 按完整帧校验、序号和操作码处理。

## 验证范围

自动化测试覆盖协议黄金帧与拆包、积木映射及等待、模式进入和退出、实体键中止、遥控键位、默认设备与手动选择优先级、Android 页面交互。Android Debug APK 构建通过。**新版 C2 编程动作尚需连接对应固件的实机验证**；模拟设备测试不能证明真实电机、红外、眼睛和语音已按预期工作。

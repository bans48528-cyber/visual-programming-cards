# 小白编程 1.0.0 测试版

构建日期：2026-09-15。安装包：`artifacts/xiaobai-1.0.0-debug.apk`。

## 安装

Android 7.0 及以上可安装。应用名称“小白编程”，包名 `com.xiaobai.remote`，与原“卡片编程”分开安装和保存作品。本包为调试签名的测试版。

将 APK 发送到手机，打开文件并按系统提示允许该来源安装。

## 使用

1. 小白开机后切换到**遥控模式**。
2. 打开 APP，点击蓝牙图标，允许扫描权限，扫描并选择小白。旧 Android 还需要打开系统定位开关；APP 不读取地理位置。
3. 扫描会展示有名称的附近 BLE 设备；选择你的小白，连接时校验 FFF0/FFF1 服务。设备广播名称不必固定为 Spark_AI。
4. 手动遥控：首页或编辑器的手柄按钮打开遥控。方向键控制移动；左正/左反、右正/右反控制电机；顶部速度 + / − 每按一次调整一档。
5. 积木编程：新建作品，放入积木，点黄色“运行”。灰色停止按钮停止程序并释放全部按键。

建议先尝试：`组合前进 1 秒 → 等待 1 秒 → 组合后退 1 秒`。定时动作结束会停机，所以这里等待的 1 秒是静止等待。

持续动作示例：`持续正转（L/M1） → 等待 2 秒 → 电机停止（L/M1）`。等待保持当前动作；持续动作本身不等待。

## 运行规则

- 运行时使用点击运行那一刻的程序快照。若随后编辑积木，新内容下次运行才生效。
- 手机保持前台运行，APP 开启时保持屏幕常亮。计时是手机调度时间，不是精确位移或角度控制。
- 顺序、等待、次数循环、嵌套循环和无限循环由手机执行。
- 双电机状态统一维护，组合动作也转换为对应四色键，避免十字键优先级遮蔽后续单电机动作。
- L 加速、R 减速；肩键发出短按/释放，速度是全局档位，不显示未经同步的绝对档位。
- 动作状态每秒重发，状态改变立即发送。停止会取消尚未发送的动作并发送全零释放。
- 完成、停止、切换到手动遥控、离开编程页、进入后台都会结束本次程序。物理断连后取消执行，重连不自动恢复。
- 断连时手机无法保证释放帧送达，是否自动停机仍取决于小白固件。
- Android 原生写入只允许 C1 遥控帧。本版本不发送 D0、B9 或字节码文件。

## 验证情况

已通过：

- 执行器自动化测试：参数拒绝、单电机和组合动作混用、定时停止、速度脉冲、嵌套循环、心跳、取消、断连、写入失败与队列取消。
- 手机控制层模拟测试：运行/停止、离开页面、后台、切换期间取消、未连接提示，仅发送 C1。
- 既有 C1 帧和传输层测试，含不发送 D0 的连接路径。
- Android APK 构建；包名、版本、最低系统版本和打包资源检查。

尚未验证：当前没有连接手机或小白硬件，未做新版 APK 的真机界面和电机动作验收。测试不代表实机已通过。

首次实机核对：四个电机键的正反方向、左转/右转、L 加速/R 减速、松手/程序结束停止、切后台停止，以及关闭蓝牙或超出范围后的主机停机行为。

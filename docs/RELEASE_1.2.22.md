## 连接后身份核对修复

现场日志显示正常小白协议连接和通知，但 INFO 第12段没有收到对应反馈，尚未读到 UID。旧实现会从第1段整轮重读，期间运行按钮因核对忙碌被禁用，且没有显示具体原因。广播名变化本身不参与小白协议选择和运行禁用条件；不能据此把正常广播名认作坏连接或 Boot 模式。

- INFO、UID、状态查询仅在响应 TIMEOUT 时对当前片用新 seq 重试一次，不再无差别重读整轮。
- 每次完整身份读取最多18秒，包含排队、原生写入和响应；响应的1800ms预算从实际发起该逻辑帧写入时开始。超时、取消、断连或模式/连接代际变化不会让排队旧请求迟发。
- 满队列被心跳/停止驱逐的未发送请求会立即取消，不等待一个不会到来的响应。
- 核对中显示“核对中”，点击只查看当前核对状态，不执行程序、不并行核对。失败提供具体段号和重新检查；取消立即终止该代读取。
- 完整 INFO 10/12片、UID、板型、版本、镜像、布局、连接epoch和升级同意条件均保留。执行、学习、升级及切型号的保护没有放宽。

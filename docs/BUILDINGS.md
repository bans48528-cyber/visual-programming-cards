# 搭建图接入

## 产品行为
所有型号主页均有「搭建图」，按型号展示内置书本图册；根据用户的测试要求，当前小白配置六本测试图册，每册八页，重复使用机器鸭 v2，共 48 页；其他型号为空。六册用于验证列表滑动、翻页及页码记忆，正式分级资料以后替换配置。无文件选择、导入、最近导入记录入口。已有作品管理保持独立。

书架上方展示「每一次翻阅，都是新发现」「把想象，搭成模样。」「选一本喜欢的图册，开启你的搭建之旅。」引导文案。图册每行三本，第四本自动换行，数量较多时在主页内容区上下滑动；手机横屏时压缩引导区间距，封面同时适应可用列宽和屏幕高度。图册内部仍左右翻页。

## 内容配置
在 building-catalog.json 对应型号数组中添加：
```json
{"id":"stable-id","name":"作品名称","description":"简短说明","file":"assets/building-models/model.io","cover":"assets/building-models/cover.png"}
```
模型资源放在 assets/building-models/，当前支持 io/ldr/mpd/dat。文件路径使用 ASCII 文件名；显示名称可为中文。id 在同一型号内保持唯一且稳定。正式资源由维护者加入构建，用户只能在列表选择。零件缺失会报错，不替换几何；包含步骤时进入步骤查看，否则显示完整模型。

## 源码与构建
### 图册配置与交互
在 `building-books.json` 按型号配置图册（数量不限）：
```json
{"xiaobai":[{"id":"test","title":"测试图册","description":"小白造型 · 搭建体验","cover":"assets/building-books/duck-cover.webp","entries":["duck-v2-test"]}]}
```
`entries` 引用同型号目录中的 id，其顺序就是图册页序；同一 id 可重复出现为多页，共享同一份模型、封面和预加载缓存，不复制模型文件。跨型号或不存在的 id 不显示，没有有效页面的书不显示。尚未分组的有效资料保留在默认图册中，避免升级时旧资料丢失。正式分级和封面由维护者提供；当前六册重复页面是用户指定的临时测试内容，原型中的其他模型和分级不进入产品。当前仅复制参考包中机器鸭的两张 WebP 图片。

封面放大翻开为蓝白双页书（横屏宽约 72%），左页图片及「去搭建」，右页名称和描述。使用触摸滑动、左右按钮和页码滑条；单页时翻页控件禁用。滑条拖动时按钮、进度和页码即时预览，松手后保持目标位置并播放翻页动画；连续改选时以最后目标为准，不被尚未完成的旧动画拉回。第二根手指、取消或旋转屏幕会取消未完成的手势。竖滑只滚动较长描述，页内按钮不触发翻页。没有自定义鼠标滚轮、悬停或键盘翻页逻辑。

图册由 `building-books.js` 管理，触控绑定在 `building-books-touch.js`，样式在独立 CSS。查看器打开时图册保留在其下方，关闭查看器回到原书原页；同一次 APP 会话中按型号和图册分别记忆页码。退出图册才回书架。关闭、型号切换和迟到的打开请求通过独立会话身份检查；旋转屏幕只整理动画，不重新加载书或模型。设置→模型→图册→书架的原生返回链保留。

`node tests/building-books-touch.spec.cjs` 验证手势取消和滑条提交；`node tests/building-books.spec.cjs` 用仅测试路由注入多页数据验证真实触摸、快速返回、各书页码记忆、查看器返回、型号隔离及屏幕适配，不添加产品内容。

`node tests/building-books-preview.spec.cjs` 使用当前实际六册配置，验证三列两排、触摸上下滑动、八页翻阅、动画期间滑块/页码/进度即时跟随目标、连续改选与取消，以及第八页进入查看器后的返回记忆。

### 离线查看器
viewer-source 是本地 lego-local-viewer 提交 fc3ed4b 的静态资源快照（不含验证样例及导入首页），原项目没有改动。上游 js/css/textures 保持原字节，许可证位于 viewer-source/licenses。App 专用 open.html/open.js/host.js/exit.html 为宿主适配。
scripts/build-viewer.cjs 将快照复制到 dist/viewer，并仅转换外围页面与 app 模块的路径、数据库名及完成动作。由正式 build:web 调用，不依赖原仓库绝对路径。

## 生命周期
主 App 保持加载，查看器在临时 iframe 中运行。退出/切换型号时移除 iframe src，释放其文档和 WebGL 上下文。设置以内部覆盖页呈现，普通选项实时更新，返回时保留同一模型实例、视角和步骤；凸点高对比在当前文档内重建渲染缓存，也保留步骤和视角。返回键先从设置回到模型，再退出到原图册，合上图册后回到列表；零件预览优先关闭。原生返回由 App 宿主转发。最后一步继续点击保持当前页面，不自动返回，也不请求上游 PHP 服务；点击返回按钮才返回原图册。外部链接由外围点击处理拦截，核心资源全部本地提供。
内置模型在打包时解压、应用自定义零件适配并收集完整依赖，生成带内容哈希的 JSON 资源包。APP 启动不读取模型；进入搭建图列表后延迟 200ms 预加载当前型号第一份模型的数据到 IndexedDB，不创建查看器或 WebGL 场景。点击时复用进行中的准备任务和持久缓存；缓存被清理时从内置资源包恢复。离开列表、切换型号、进入后台时取消预加载，迟到任务不会打开页面或覆盖其他型号。模型及依赖更新会改变哈希和缓存键。数据库独立命名，不读取验证站点的最近模型。此版本不承诺跨退出保存搭建进度，设置往返保留当前步骤。

## 验证与边界
node tests/buildings.spec.cjs：空列表、无导入入口、分型号隔离、测试用模型子路径渲染、设置往返、末步停留、主页退出和 iframe 释放。
node tests/device-models-ui.spec.cjs：现有型号、草稿、迁移、异步切换回归。
自动化用的简化零件模型仅通过测试路由注入，不进入列表或安装资源。机器鸭 v2 及其六册重复页面是用户明确指定的测试内容。实体 Android 性能、GPU/触摸/后台恢复/系统返回及新版安装包离线运行仍待实机验收。

### 凸点样式原位更新
保留查看器解析后的源几何数据；关闭设置时，如凸点高对比有变化，重建渲染缓存并释放旧 GPU 几何与材质，不重新加载文档。保留原步骤、视角和缩放。普通选项仍即时生效。代价是查看期间保留源几何数据，关闭搭建图后随 iframe 一起释放。

### 预处理与预加载验证
`node tests/building-preload.spec.cjs` 检查启动无模型工作、列表只预加载一份且无 3D 脚本、原始 IO 不进入输出、打开时不解压或逐个请求零件、持久缓存、内容版本失效、型号切换取消。`node tests/viewer-settings.spec.cjs` 检查设置卡片、手机横屏尺寸以及凸点切换保留步骤和视角。

### 整页过渡
主页与编程、遥控、搭建图查看器之间通过 `page-transitions.js` 移动真实整页，进入从右向左，返回相反；出场 300ms ease-in-out、入场 280ms ease。弹窗和分类不参与。连续返回合并为最新请求并完成被替代的关闭任务；后台、窗口调整和蓝牙转场及时清理动画。搭建图先呈现可返回的加载页，入场完成后才设置 iframe 地址并创建 3D 场景，收到查看器就绪消息后隐藏加载页。加载中返回会使旧任务失效。`npm run test:transitions` 验证方向、时长、快速返回、遥控返回目标及弹窗隔离。

# 幼儿小方块 TC-01 接入

2026-10-08。型号 ID 为 `tc01`，广播名称按用户提供的 `Drluc` 精确匹配。

## 已确认协议

发送 ASCII 文本 `KEY_DATA=xxxx`。四位按顺序为左正、左反、右正、右反，1启动、0停止。同一电机正反互斥。

- 左正：`KEY_DATA=1000`
- 左反：`KEY_DATA=0100`
- 右正：`KEY_DATA=0010`
- 右反：`KEY_DATA=0001`
- 全停：`KEY_DATA=0000`

左右电机状态合并发送；停止一个电机保留另一个电机状态。不添加小白/Spark/LBS帧头、校验、模式指令或AT命令。

## 积木和遥控

电机：定时正转、定时反转、持续正转、持续反转、单电机停止、全部停止。参数选择 L/R，定时使用秒。逻辑：等待、有限循环、一直循环。没有未获协议支持的调速、传感器或显示积木。

手机执行逻辑并发送状态字符串，定时动作结束仅停止对应电机；程序结束或取消发送全部停止。手动遥控支持双手触控，同一电机按最后按下的方向执行，松手更新完整状态，关闭遥控发送全停。只报告发送情况，不推断电机实际转动或设备执行状态。

## 待确认（当前不能实机连接）

用户尚不清楚下列信息，且本轮 ADB 未检测到手机：

1. 产品使用 BLE 还是经典蓝牙串口。
2. 若为 BLE：服务/写入特征 UUID 和支持的写入方式；通知特征可选。
3. 字符串是否需要 CR/LF/CRLF，还是无结束符。
4. 是否需要持续重发、最小指令间隔、断连停车行为。

`tc01-profile.js` 保留 null，连接前拦截未确认配置。没有套用其他型号 UUID。Android 已预留可配置 BLE 写入通道，包括仅写、无通知的特征；如实物为经典蓝牙，需要另行接入串口传输。未验证前不自动试发不同结束符，不添加未确认心跳。

## 文件和隔离

- `tc01-model.js`：型号、9个积木、示例、Drluc筛选。
- `tc01-protocol.js`：字符串编码、最新状态发送、连接配置校验。
- `tc01-runner.js`：手机侧计时/循环/取消。
- `tc01-ui.js` / `tc01.css`：四按钮遥控。
- `Tc01Frame.java`：原生独立 profile 的精确字符串白名单；断开时使用相同结束符的全停字符串，不发送 C1/C2。

作品、草稿、默认蓝牙设备由既有分型号机制保存，自定义蓝牙名称共用原本地名称表。图标为通用方块标识，非产品实物图。

## 验证边界

`npm run test:tc01` 使用明确标注的模拟BLE UUID/结束符，验证编码、状态合并、定时/循环、取消、双手松开和关闭遥控、默认设备/草稿隔离、未配置时零连接零写入。模拟值只出现在测试文件，未写入产品配置。

Android Java 编译和原生字符串校验通过；小白、LBS2206、Spark AI及公共蓝牙回归通过。没有进行本轮实体控制、APK安装或蓝牙参数实测。

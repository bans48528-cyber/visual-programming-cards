# 小白自学习口令积木：手机端交付

日期：2026-10-21。对接依据为同目录《自学习口令对接契约.md》v1.0，
来源 `D:/XiaoBaiDev/ASRPRO/xiaobai_commands/mobile_protocol.md`。

## 使用

小白的「动态」分类新增「自学习口令」积木，作品只保存
`{id:"self-learned-wait",params:{slot:1}}`，编号范围为 1–10。
原「等待词条」积木仍使用固定词条与 0x51，不修改旧作品的含义。

点击参数「指令N」打开紫色浮层，可左右选择编号。离线可以编辑编号；
连接、通知订阅、编程模式、300ms 心跳与完整能力确认完成后才能学习。
进入编程页及重连会重新查询，左右选择不重复查询。

未学位置点击学习；已学位置点击备忘只修改本机文字，点击「重新学习」
须确认所有引用这个编号的作品都会改用新口令。删除积木不向设备发清除命令。
备忘最多 80 字，留空显示「指令N」，不包含在下发帧或作品内容中。
存储键为 `xiaobai:<UID96>:<slot>`，UID 由 0x56 两段读取并拼成 24 位十六进制字符串。

## 设备反馈与运行

- 进入编程模式后立即保持心跳，在约 250ms 稳定窗口后，通过 0x04 实际确认 mode=4，再读取 UID/十槽；只读状态查询超时最多重试一次，不重发动作。
- 0x52 查询全部十槽及能力；只有能力低四位齐全，位图才转成已学习/未学习。
- 0x53 学习；D2 受理仅显示跟随小白提示，不代表已保存。
- D3/0x08 的阶段 1、2、3、9、10 更新实际逐遍采集/重试；只有阶段 4 且最终状态已学才弹备忘。
- 0x54 取消；ACK 后继续等待实际终态，3 秒无确认则保留未知状态并停止。
- 每次学习及等待使用新的持久 uint32 task，按 UID 递增，跨断连及 APP 重启不复用；耗尽或存储失败会拒绝发送。
- 全作品预检查包括循环内的引用，未学定位到对应积木，未知先查。
- 新固件所有程序通过 0x57 声明运行（持续覆盖积木间隙）。明确不支持扩展的旧固件可运行原有积木，不能运行自学习积木；响应超时不会当作旧设备放行。
- 所有 C2 帧均保留至少 40ms 的 TX→TX 与 RX→TX 保护窗，前次发送完成后开始计时；不完整通知分片也更新接收时间，排队结束后再次检查取消。
- 0x55 等待，只接受当前 task/slot 的阶段 11 就绪后新命中。D2 受理后若未收到真实阶段 11，每隔至少 1 秒最多补发两次完全相同的原帧（seq/task/slot 不变），不分配新任务、不延长原准备时限；就绪、终态、停止、断连或模式变化后清理并拦截排队重试。重复命中、其他位置、旧任务、取消均不推进。
- 正常结束发送同 runId 的结束声明；停止、断连、模式切换和心跳错误会取消运行，不自动续跑。
- 停止写入及旧执行器清理未完成前保持操作锁，防止旧停止影响新任务。

手机没有模拟采集进度。受理后显示「请跟随小白语音提示」；实际阶段 1/3 来自
原厂提示音结束且录制请求入队，分别显示「请说第一遍／请再说一遍」，不代表已检测到讲话。
阶段 2 才表示第一遍有效；阶段 9/10 等待下一次真实准备。计时器仅用于有限重发和超时取消，
不生成就绪、有效录入、命中或保存成功。拒绝弹窗显示「学习未完成」并保留设备具体原因。

## 硬件联调边界

本轮手机软件回归覆盖协议会话、UI、执行器、双眼点阵、Android 原生帧门禁、蓝牙连接与遥控导航。
下位机于 2026-10-21 交付的真实记录：ASRPRO v1.4.2 已由用户烧入，PY32 保护窗为 40/40ms，
完整读回校验 31892 字节。指令 2 两遍学习返回阶段 1/2/3/4，位图 1→3，完全断电后仍为 3；
同一连接与同一 run 的两个新 task 分别由两次新发声命中，指令 1 也命中。当前指令 1、2 已学。
这些为下位机电脑 BLE 联调结果；本轮未重刷固件、未覆盖口令、未修改用户手机备忘。
更新 APK 后仍需用户参与手机端实际录音和连续等待验收，软件测试不能替代实机结果。

跨客户端编号同步仍是独立限制：设备保留本次上电中电脑较大的 task/run，手机编号可能被拒绝。
电脑联调切回手机前须将小白完全断电（包括 USB 反向供电）再启动；已学模板按已验证的存储保留。
本补丁不清空用户存储、不跳大编号、不放宽旧 task 过滤。

交接向量中的 `stop_program` 示例 seq=15，与沿用的控制帧门禁 seq=0 有出入。
手机保持现有 0x05/seq=0 停止格式，不放宽原生校验。其余扩展帧使用非零 seq。

手机更新包版本为 1.2.4（versionCode 10），保持原包名和调试签名以正常覆盖更新。
手机不在 ADB 列表时先交付 APK；连接后仅引导到系统安装确认界面，由用户完成确认。

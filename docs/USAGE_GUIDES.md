# 造型配套程序与使用指南

## 当前内容

仅为小白设备的入门图册接入两套正式资料：

| 造型 | 配套程序 | 指南页数 |
| --- | --- | --- |
| 小白机器人 | 开心表情、声音 P05 | 5 |
| 摇摆模型 | 双眼问号点阵、等待向前倾倒、晕眩表情 | 4 |

资料来自用户提供的两份 PPTX 及其视频，原文件保留。其余造型没有配置配套程序，完成搭建后继续返回原图册页。小风扇新资料本次按用户要求暂不接入。

## 配置与资源

- `building-catalog.json` 中造型的 `companionProgram` 指向内置程序 ID。
- `companion-programs.json` 的 `programs` 保存编辑器工作区状态及可选 `guideId`；`guides` 保存逐页文字、图片和视频引用。
- `assets/usage-guides/xiaobai/robot/` 与 `swing/` 是随软件离线打包的资源。
- `companion-programs.js` 仅按需读取轻量配置；`usage-guide.js` 仅给当前页设置媒体源，不预载其他视频。
- 图片保留原比例和透明通道；截图采用无损 WebP，主机图片采用高质量 WebP。视频只做 faststart 元数据重排，音视频内容与源文件一致。

新增配套程序时，可以只配置 `state`，不配置指南。支持已有积木、循环和暂存工作区结构。若增加新的指南页，在 `pages` 中配置 `title`、`text`、`media`，可选 `icons`、`tips`、`caption`。

## 打开、保存与返回

图册中已配置配套程序的造型，在“去搭建”下方显示“去编程”。它直接打开配套程序和指南，返回后恢复原图册及造型页；没有配置程序的造型不显示此入口。读取期间保留图册，关闭、翻页或切换型号会使过期请求失效。

查看器完成按钮发送独立的 `complete` 事件；返回按钮仍发送 `close`。只有配置了配套程序的造型会进入编程界面。

配套程序是独立的内存会话，自动保存和离开时都不会写入用户作品，也不会覆盖上一次打开的用户作品。确认“另存”后才创建新的用户作品，保留 `companionId`、`guideId` 引用；副本后续按普通作品保存，重新打开时自动显示对应指南。

从搭建完成进入的程序会保存一次性的图册恢复回调，回到主页后恢复原图册、原造型页；直接从“我的作品”重开副本则正常返回作品列表。程序打开取消、型号切换或过期异步结果均不会重新打开已离开的页面。

指南收起保留当前页和视频播放位置并暂停视频。切页、关闭或离开会释放旧媒体源。进入蓝牙连接界面时临时隐藏并暂停指南，返回编程后恢复原状态。原有蓝牙连接、编程模式、心跳和程序运行逻辑继续由现有代码管理。

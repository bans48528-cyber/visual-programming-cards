# 小白版积木范围

更新日期：2026-09-15。基于提交 `ddb4db7`，分支 `xiaobai/remote-blocks`。

## 当前交付范围

已完成积木库筛选、双电机端口命名、示例调整和手机执行器。运行按钮执行当前程序快照，停止按钮取消程序并释放全部按键。原有手动遥控入口保留，切换前等待程序释放。

小白使用与 Spark_AI 相同的 C1 十键协议，已由用户确认。下表是该协议配合产品定义可以实现的功能，不代表已完成实际电机动作验证。

## 保留的 16 种积木

另有固定的“开始”入口，不计入素材积木数量。

| 分类 | 积木 | 参数/执行含义 |
| --- | --- | --- |
| 单电机 | 电机正转 | L/M1 或 R/M2；运行指定秒数后释放对应电机键 |
| 单电机 | 电机反转 | L/M1 或 R/M2；运行指定秒数后释放对应电机键 |
| 单电机 | 持续正转 | 设置指定电机持续正转，不等待 |
| 单电机 | 持续反转 | 设置指定电机持续反转，不等待 |
| 单电机 | 电机停止 | 释放指定电机的正反转键 |
| 组合 | 组合前进 | 指定秒数后停止组合移动 |
| 组合 | 组合后退 | 指定秒数后停止组合移动 |
| 组合 | 组合左转 | 指定秒数；按产品定义为左停、右正转 |
| 组合 | 组合右转 | 指定秒数；按产品定义为左正转、右停 |
| 组合 | 组合持续移动 | 选择前进、后退、左转或右转，不等待 |
| 组合 | 组合停止 | 清除组合方向和两侧电机键，停止全部电机 |
| 组合 | 速度加一档 | 肩键按下并释放；全局三档速度，最高三档 |
| 组合 | 速度减一档 | 肩键按下并释放；全局三档速度，最低一档 |
| 逻辑 | 等待时间 | 手机计时，保持当前电机状态；等待本身不停止电机 |
| 逻辑 | 循环次数 | 手机执行指定次数，允许嵌套 |
| 逻辑 | 循环 | 手机持续循环，直到停止、退出或断连取消 |

定时动作结束后停止，与持续动作加等待有所区别。例如“电机正转 1 秒 → 等待 2 秒”表示转 1 秒再停等 2 秒；“持续正转 → 等待 2 秒 → 电机停止”表示转 2 秒后停。

## 移除/替换

| 原积木 | 处理原因 |
| --- | --- |
| 电机功率、组合电机功率 | 原 25/50/75/100% 不能直接映射三档遥控；改为全局速度加/减一档，不宣称独立调速 |
| 组合电机方向 | 原积木配置 Spark 电机配对极性；小白首版采用产品定义的固定方向，不提供这一配置。以后可另做手机端方向转换 |
| 超声波传感器 | 未确认距离数据回传能力 |
| 灰度传感器 | 未确认灰度数据回传能力 |
| 按键传感器 | 未确认外接触碰状态回传能力 |
| 主机按键 | 未确认主机按键状态回传能力 |
| 演奏音、点阵 | C1 十键没有已定义的音符播放或点阵控制映射 |

传感器、声光分类及点阵音符示例已移除。主机自带红外、眼睛灯、喇叭不等于手机可通过 C1 读取或控制，暂不新增对应积木。电机端口仅显示 L/M1、R/M2。

## 执行规则与实机待验证项

- 用户已确认 A=左正、B=左反、X=右正、Y=右反、L=加速、R=减速；代码已采用，实机动作仍待验收。
- 统一保存左右电机和全局速度状态。组合动作接管双电机；组合移动后再执行单电机动作，须先解除十字键优先级并转换为等价的单电机状态。
- 速度肩键采用按下/释放脉冲，避免将增减事件当作持续电机状态重发；不在缺少确认时显示绝对档位已同步。
- 执行期间保持连接，及时发送状态变化并按需要重发；计时、循环必须可取消。
- 程序结束、用户停止、离开运行页面或进入后台时，取消执行并尝试发送全零释放。不得使用 B9 作为小白停机指令。
- 物理断连后手机无法保证释放帧送达。必须实测小白固件的断连/超时停机行为；重连后不自动恢复动作。
- 固件无回传的传感器条件不能通过手机计时模拟。

## 作品兼容

小白版使用独立的 `xiaobaiProjectsV1`、`xiaobaiActiveProjectV1`、`xiaobaiVisualProgramV1` 存储键，不自动迁移原 Spark 作品，避免将不支持的积木或 E–H 端口静默改写。

# 小白版积木范围

更新日期：2026-09-17。积木目录以《小白控制功能表》为准，图标来自 `图标SVG.ai` 的 23 个 SVG 画板。

## 当前积木目录

固定的“开始”入口不计入积木数量。

| 分类 | 积木 |
| --- | --- |
| 电机（6） | 电机正转、电机反转、持续正转、持续反转、电机停止、电机功率 |
| 组合电机（7） | 前进、后退、左转、右转、持续移动、组合停止、组合功率 |
| 逻辑（4） | 等待时间、循环次数、一直循环、等待红外 |
| 动态（5） | 显示表情、显示数字、关闭显示、语音播报、等待词条 |

“等待红外”属于逻辑类，条件支持大于或小于，阈值范围为 0–100。电机功率和组合功率均为 1、2、3 档。持续移动支持前进、后退、左转和右转。

动态类内置功能表规定的 10 个表情、10 条播报词条和 10 条识别词条。显示数字范围为 0–100。

## 图标

AI 文件中的 23 个画板已分别导出为 SVG。持续移动会随所选方向切换图标；循环次数和一直循环共用循环图标；关闭显示使用数字显示图标并增加 OFF 标识。积木中的图标尺寸为上一版的 140%。

## 执行说明

等待时间和循环在手机端执行。积木动作按 C2 编程协议发送到下位机；定时电机、等待红外和等待词条收到匹配的 DONE 后继续。等待红外固定使用中间通道。手动遥控继续使用 C1。

## 作品兼容

旧作品中的速度加一档、速度减一档仍可读取和运行，但不再出现在新版积木选取栏中。电机端口内部仍保存为 `L/M1`、`R/M2`，界面显示为 `L`、`R`。

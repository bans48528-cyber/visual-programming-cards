# 小白版积木范围

更新日期：2026-10-16。保留原功能表目录，并按用户要求新增等待倾倒和点阵表情；本次小白图标来自最新 `图标SVG.ai` 的 26 个 SVG 画板。

## 当前积木目录

固定的“开始”入口不计入积木数量。

| 分类 | 积木 |
| --- | --- |
| 电机（6） | 电机正转、电机反转、持续正转、持续反转、电机停止、电机功率 |
| 组合电机（7） | 前进、后退、左转、右转、持续移动、组合停止、组合功率 |
| 逻辑（5） | 等待时间、等待倾倒、循环次数、一直循环、等待红外 |
| 动态（6） | 显示表情、点阵表情、显示数字、关闭显示、语音播报、等待词条 |

“等待红外”属于逻辑类，条件支持大于或小于，阈值范围为 0–100。电机功率和组合功率均为 1、2、3 档。持续移动支持前进、后退、左转和右转。

动态类内置功能表规定的 10 个表情、10 条播报词条和 10 条识别词条。显示数字范围为 0–100。

## 图标

26 个画板导出至 `assets/blocks/xiaobai-20261016/`，画板映射和源文件摘要记录在同目录的 `source.json`。小白独立选择新图标，其他型号继续使用原资源；开始、循环、持续移动和关闭显示均有对应图形。数字和预设表情在程序中仍显示实际参数预览。

## 新积木的编辑与保存

- 等待倾倒：方向可选向前、向后、向左、向右。向前参数按用户给定文字显示“先前倾倒”，其余显示“向后倾倒 / 向左倾倒 / 向右倾倒”。
- 点阵表情：左右眼各自保存 `leftPattern` / `rightPattern`，互不覆盖。按用户 2026-10-16 的最新确认，每眼 **8×8，四角没有 LED**，共 60 个可编辑点；此规格覆盖旧眼睛资源的 7×7 描述。编辑数据为从左到右、从上到下的 64 个 0/1，四角固定为 0。这里是编辑器存储格式，并非已确认的硬件位序。
- 触控点亮或熄灭、滑动绘制、撤销/重做、草稿和作品保存复用现有编辑器。Spark AI 保持原 5×5 编辑与执行协议。

用户确认目前还没有这两个功能的硬件协议，本轮仅完成积木构建。含这两个新积木的程序会在运行前明确提示协议尚未提供，整段不进入硬件执行，也不会先运行前面的运动积木。已有小白积木仍按原协议执行。

后续需要提供倾倒操作码、方向编码与等待完成回报，以及自定义点阵命令、左右眼编号、位序/分包方式和刷新时机；不得复用 Spark AI 编码或自行分配小白操作码。

## 执行说明

等待时间和循环在手机端执行。积木动作按 C2 编程协议发送到下位机；定时电机、等待红外和等待词条收到匹配的 DONE 后继续。等待红外固定使用中间通道。手动遥控继续使用 C1。

## 作品兼容

旧作品中的速度加一档、速度减一档仍可读取和运行，但不再出现在新版积木选取栏中。电机端口内部仍保存为 `L/M1`、`R/M2`，界面显示为 `L`、`R`。

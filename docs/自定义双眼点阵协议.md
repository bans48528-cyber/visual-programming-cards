# 自定义双眼点阵 — C2 扩展 0x43

日期：2026-10-19。手机端原有编辑器只保存图案，并未定义下发协议；本扩展随手机端与主控固件一起实现。用户确认当前眼板为每眼 8×8、四角无 LED。

## 坐标与数据

- 面向眼板正面，画面左眼为 L、右眼为 R；每眼 x 从左到右 0..7，y 从上到下 0..7。
- 编辑器 `leftPattern` / `rightPattern` 各 64 个 0/1，索引 `y*8+x`。
- 线上转换为 16 个列字节：0..7 左眼、8..15 右眼，bit0=最上行、bit7=最下行，1=亮。
- 每眼四角（索引 0/7/56/63）恒为 0；手机打包和固件显示层均屏蔽四角。
- TM1640 显存地址 0..15 对应这 16 列。2026-10-19 真实 BLE 下发 L/R 后，用户确认面向正面左 L、右 R，左右/上下方向正确。其它版本眼板如接线不同，只修正显示驱动映射，不改变手机保存格式。
- 旧 14 列预设表情与数字保持原映射，刷新时清零末两列，避免自定义图案残留。

## 帧与操作码

沿用 17 字节 `5A 97 98 0A C2 DATA[10] SUM A5`。`DATA=[seq,0x43,transfer,part,c0,c1,c2,c3,c4,c5]`。

| 字段 | 规则 |
|---|---|
| seq | 每包独立编号 1..255，按现有 Link 递增，用于匹配 D2 |
| transfer | 本幅图编号 0..255；三包相同，下一幅递增并允许回绕 |
| part=0 | 列 0..5；总是开始新上传，替换旧半包 |
| part=1 | 列 6..11；必须紧接同 transfer 的 part=0 |
| part=2 | 列 12..15，最后两个字节必须为 0；必须紧接同 transfer 的 part=1 |

在编程模式下依次发送三包，每包等待成功 D2 后继续。part=0/1 只缓存；part=2 才整幅刷新，停止预设动画。仅占 RAM，不写 Flash；重启恢复默认表情。

Android 原生蓝牙发送层 `ProgramFrame` 同步允许 `0x43`：保留 17 字节长度、帧头、校验和及非零 seq 校验；part 只允许 0/1/2，part=2 的最后两个数据字节必须为 0。分包顺序与 transfer 配对仍由主控通过 D2 确认。`test:android-native` 将手机 JavaScript 生成的帧交给实际 Java 校验器测试，避免仅通过网页模拟测试而在手机端被拦截。

## 回报与异常

- 每包成功后回一次 `D2 DATA=[seq,0x43,0,transfer,part,0,0,0,0,0]`。这是单次 ACK，无 200ms DONE 重报。
- 非法 part、错序、transfer 不匹配、尾部保留位非零、相邻包间隔 ≥1000ms：返回 `BAD_PARAM=1`，清除半包，原画面不变。任何新的 part=0 可重开上传。
- 旧固件返回 `BAD_OPCODE=2`，手机停止该程序并显示设备拒绝指令。手机不盲重发、不继续后续积木。
- 校验坏帧由通用解析器丢弃；手机等不到 ACK 时在 1500ms 后停止程序。恢复时从 part=0 重传整幅。
- 心跳、状态查询、读取红外、幂等进入编程模式不打断半包；心跳不会延长半包的 1000ms 有效期。
- 停止程序、任何其它动作、模式退出、断连/心跳超时导致退出，均清除半包。STOP 保留已经显示的完整图案；退出编程模式恢复默认表情。
- 新点阵包遵循现有动作抢占规则：取消旧等待任务与 DONE 重报。非编程模式静默忽略，与原动作类 C2 一致。
- 点阵发送起点之间以及收到通知至下一点阵包至少 30ms；心跳继续使用手机端现有 400ms 周期。

## 黄金帧与验收

示例 transfer=33，列数据 `00 01 00 00 00 00 80 08 04 00 00 00 00 00 00 40`：

```text
5A 97 98 0A C2 01 43 21 00 00 01 00 00 00 00 BB A5
5A 97 98 0A C2 02 43 21 01 80 08 04 00 00 00 48 A5
5A 97 98 0A C2 03 43 21 02 00 00 00 40 00 00 FE A5
```

黄金帧入库 `ble_v2_golden_frames.json`，C 解析与手机打包测试使用相同向量。自动化覆盖错序、残包、超时、取消、切模式、tick 回绕、bit7/末两列和旧显示清理。实板验收应确认：双眼独立、左上到右下坐标、最下行和最右列、四角熄灭、关闭显示及预设表情恢复。
